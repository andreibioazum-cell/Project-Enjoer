# Enjoer — блочный мир

Горизонтальная игра от первого лица на **чистом C**: процедурный воксельный
ландшафт с травой, землёй, камнем, песчаными берегами, водой и деревьями.
Старого парка, обби, монет и ботов больше нет.

## Управление

- **По умолчанию — ходьба.** Чёрный джойстик слева двигает игрока по земле,
  круглая кнопка справа отвечает за прыжок. Действуют гравитация и столкновения.
- **Белая кнопка «Полёт» сверху** включает/выключает полёт. Галочка обозначает
  включённый режим. В полёте кнопка прыжка полностью скрывается.
- В режиме полёта джойстик двигает вдоль взгляда, в том числе вверх/вниз.
  Отпустил джойстик — завис. Выключил полёт в воздухе — начинаешь падать.
- Свайп по правой половине поворачивает камеру. Движение, обзор и прыжок
  поддерживают независимые пальцы, в том числе во время переключения режима.
- При отмене жеста, потере фокуса или изменении размеров удержания сбрасываются.
  Отменённое касание переключателя **не включает** полёт.

**ПК:** `W A S D` — движение, стрелки или перетаскивание справа — камера,
`Space` — прыжок, `F` — переключить полёт. Только в полёте `Space` / `Shift`
поднимают / опускают игрока. В воде удержание прыжка позволяет всплывать.

На Android используется `sensorLandscape`: обе горизонтальные ориентации.
HUD минимален: стик без подложки, абсолютно чёрная ручка без обводки и толстое
чёрное внешнее кольцо, простой белый прицел, переключатель и условный прыжок.
Панели названия, счётчика монет и текстовых подсказок нет.

## Генерация и рендер

- Мир генерируется чанками **16×16×40**. В памяти остаётся скользящий кэш
  **9×9 чанков**; по мере движения загружаются следующие участки.
- Seed и мировые координаты определяют каждый блок. Возвращение в место,
  выгруженное из кэша, восстанавливает тот же рельеф и деревья. Генерация
  корректно обрабатывает отрицательные координаты и стыки крон между чанками.
- Текущий seed — `RBX_WORLD_SEED` в `rbx/rbx_internal.h`. У спавна есть
  небольшая безопасная поляна, остальная местность определяется шумом высот.
- Рисуются **только открытые грани**, без внутренних поверхностей блоков.
  Чанки отсекаются по видимости и обходятся от ближних к дальним.
- Собственные процедурные текстуры травы, земли, камня, песка, воды, коры,
  срезов ствола и листвы имеют mip-уровни против ряби вдали.
- Глубина и UV интерполируются перспективно через **1/z**. Сохраняются
  исправления переполнения цветовых каналов тумана и билинейного апскейла.
- 3D рисуется в полном разрешении до 1.5 Мп, выше — в половинном с плавным
  целочисленным апскейлом. HUD и TTF-текст остаются в разрешении экрана.

Это генератор исследуемого блочного мира с ходьбой и полётом; добыча и установка
блоков, инвентарь и крафт пока не реализованы.

## Превью без Android

```sh
tools/preview/build.sh
./preview --port 8090 --assets game/assets
# http://localhost:8090
```

По умолчанию кадр горизонтальный, **960×540**. Можно передать `--w` и `--h`.
Браузер вписывает кадр в окно без растяжения, рамки телефона и лишних надписей.
Тот же C-код рендерит RGBA-кадры; события нескольких пальцев передаются с их ID,
по порядку, с объединением лишних move-событий.

## Проверки

```sh
tools/tests/run.sh
SANITIZE=1 tools/tests/run.sh
```

- `render.c`: цветовые каналы, билинейный апскейл и stride, глубина против
  пересечений лучей, отсечение, направление камеры, текстуры и mip-уровни;
- `controls.c`: обычная ходьба без подъёма от наклона камеры, одиночный прыжок,
  полёт/зависание, возврат гравитации, мультитач, отмена кнопки и жестов,
  столкновения с вокселями, геометрия и состав HUD;
- `world.c`: воспроизводимость seed, все материалы, границы чанков/деревьев,
  отрицательные координаты, ограниченный кэш и восстановление после возврата.

Sanitizer-режим включает ASan, UBSan и проверку переполнений float-to-int.
Сборки и временные данные находятся в игнорируемом `build-tests/`.
GitHub Actions YAML не изменяется; тесты запускаются командами выше.

## Структура

```text
main.c                     Android NativeActivity, цикл и ввод
runtime.h                  общий API рантайма
core/                      состояние, строки, массивы, лог, Android-клавиатура
graphics/                  2D/HUD, текст, текстуры, TTF-движок
sound/                     WAV, микшер, Android AudioTrack
rbx/
├── rbx_game.c             init/update/draw, сброс ввода
├── rbx_terrain.c          шум высот, слои, вода и деревья
├── rbx_world.c            кэш чанков и меши открытых граней
├── rbx_render.c           отсечение, растеризатор, UV, глубина, апскейл
├── rbx_shapes.c           кубы и грани блоков
├── rbx_material.c         процедурные текстуры и mip-уровни
├── rbx_player.c           ходьба/прыжок/полёт, коллизии, камера
├── rbx_input.c            мультитач, стик, прыжок, переключатель
├── rbx_scene.c            камера первого лица и блочная сцена
└── rbx_hud.c              минимальные органы управления
game/                      AndroidManifest, Java-мост, шрифт и звуки
tools/preview/             нативная сборка для браузерного превью
tools/tests/               регрессионные тесты без Android
```

Каждый `.c` — отдельная единица компиляции, не больше 500 строк, без `include .c`.

## APK

Сборка выполняется существующим GitHub Actions workflow: CMake + NDK,
`arm64-v8a` и `armeabi-v7a`, Android API 29+. Артефакт называется
**Enjoer-Messenger-APK-Android10-14-arm64-arm32** (имя существующего workflow
сохранено). `CMakeLists.txt` содержит все новые единицы компиляции движка.
