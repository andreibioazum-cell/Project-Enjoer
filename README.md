# Enjoer — 3D-плейс

Вместо мессенджера: **заходишь в игру — сразу 3D**, как в Roblox.
Написано **целиком на C** поверх того же софтверного рендера, что раньше
питал Cubic Battle 4 / DimScript:

- программный рендер `graphics/` (HUD: круги, текст, прямоугольники);
- собственный **3D-растеризатор** в `rbx/rbx_render.c` (кубы, z-буфер,
  перспектива, туман, освещение граней, плавный апскейл);
- TTF-шрифт `graphics/ttf/` и `game/assets/fonts/ChillRoundGothic_Heavy.ttf`;
- рантайм в `core/` и звук в `sound/`.

Каждый `.c`-файл — отдельная единица компиляции (без «include .c»),
в каждом не больше 500 строк.

## Что внутри

Короткий экран «Заходим в игру…», и ты уже на зелёной baseplate:

- **вид от первого лица**, без модели своего персонажа перед камерой;
- дом, радужный обби, башня, деревья, бассейн, лава, батут;
- боты гуляют по карте;
- монеты и **свободный полёт** с сохранением столкновений со стенами;
- **чёрный джойстик слева** — вперёд/назад и в стороны;
- **свайп справа** — поворот камеры, одновременно с полётом вторым пальцем.

Потяни джойстик вверх — летишь туда, куда смотришь. Посмотри выше или ниже,
чтобы набрать или сбросить высоту. Отпусти джойстик — зависнешь на месте.
Правая половина экрана свободна от кнопки прыжка. Монеты собираются и при
подлёте на уровне глаз; лава по-прежнему возвращает на спавн.

## Превью на ПК (без Android)

```sh
gcc -O2 -std=c99 -Itools/preview/compat -I. \
    core/log.c core/state.c core/strings.c core/arrays.c \
    graphics/gfx_frame.c graphics/gfx_draw.c graphics/gfx_texture.c \
    graphics/gfx_text.c graphics/ttf/ttf_outline.c graphics/ttf/ttf_font.c \
    rbx/rbx_render.c rbx/rbx_world.c rbx/rbx_player.c rbx/rbx_input.c \
    rbx/rbx_scene.c rbx/rbx_hud.c rbx/rbx_game.c \
    tools/preview/host_compat.c tools/preview/host_main.c \
    -lm -lpthread -o preview
./preview --port 8090 --assets game/assets
# открой http://localhost:8090
```

`W A S D` — полёт, пробел / `Shift` — выше / ниже, стрелки или перетаскивание
**правой половины** — камера. Сенсорное превью поддерживает несколько пальцев:
слева джойстик, справа обзор. При отмене касания, смене размеров или потере
фокуса удержания сбрасываются и игрок не продолжает лететь сам.

## Качество картинки

- 3D рендерится в **полном разрешении** на экранах до ~1.5 Мп; на более
  крупных — в половинном, но с **плавным (билинейным) апскейлом**, а не
  дублированием пикселей блоками;
- исправлено переполнение цветовых каналов при смешивании с туманом и
  билинейном апскейле — удалённые монеты и контрастные края не «радужат»;
- глубина интерполируется как **1/z**: платформы и монеты корректно закрывают
  друг друга; отсечение по пирамиде видимости убирает лишнюю работу;
- апскейл использует целочисленное смешивание и кэш координат X, без повторных
  вычислений с плавающей точкой для каждого выходного пикселя;
- текст запекается в атлас на 48px и сэмплируется билинейно — гладкие
  глифы при любом масштабе интерфейса.

## Проверки без Android

```sh
tools/tests/run.sh
SANITIZE=1 tools/tests/run.sh  # AddressSanitizer + UndefinedBehaviorSanitizer
```

Проверяются цвета монет на разных дистанциях, апскейл (в том числе нечётные
размеры/stride), глубина против пересечений лучей, ближнее отсечение,
полёт вдоль взгляда, зависание, столкновения, одновременные касания с разными
ID, отмена/отпускание жестов, камера первого лица и чёрная ручка джойстика.
Бинарники и временные данные остаются в игнорируемом `build-tests/`.

## Сборка APK

Каждый push собирает APK в GitHub Actions (`build-android`): CMake + NDK
(`arm64-v8a` и `armeabi-v7a`, API 29). Артефакт — **Enjoer-APK-Android10-14-arm64-arm32**.
